## Lo que NO SABES y necesitas investigar

### Tecnico / Obra
- Como conectar tachos de 500L a canillas (presion CO2, tuberias, distancia)
- Normativa bromatologica para servicio de cerveza artesanal
- Tipo de pintura epoxi para piso y preparacion
- Tecnica de fileteado porteno (contratar especialista?)
- Si la "bajada izquierda" es rampa o desague
- Cajas industriales: normativa IRAM, tamano por circuito

### Tecnologia
- Como chippear una PS3 legalmente (o si existe alternativa legal)
- Que herramienta AI usar para fotos "de ninos" en tiempo real
- Si el server local puede manejar AI + POS + KDS al mismo tiempo
- Red separada para clientes vs POS
- Camaras: IP o analogicas, grabacion local

### Negocio
- Margen objetivo por producto (cuanto queres ganar por pizza?)
- Capacidad maxima del local (cuantas personas?)
- Horario de apertura
- Proveedores de bebidas (vermut, moscato, gin)
- Permiso de transmision publica de partidos

### Marketing
- Identidad visual (logo, colores, tipografia)
- Nombre para las experiencias (show cerveza, retro gaming)
- Estrategia de contenido para Instagram
